# Contributing to PranaCode+

Thank you for your interest in contributing to PranaCode+!

PranaCode+ is a multi‑paradigm programming language designed to unify
crypto, chain logic, finance, governance, and high‑level systems into a
single expressive ecosystem.

We welcome contributions in the following areas:
• compiler development (lexer, parser, AST, runtime)
• standard library modules (crypto, chain, finance, contracts, governance)
• documentation improvements
• examples and tutorials
• bug fixes and performance enhancements

---

## How to Contribute

### 1. Fork the Repository
Create your own fork of the PranaCodePlus repo.

### 2. Create a Feature Branch
Use descriptive names such as:
`feature/crypto-module`, `fix/parser-bug`, `docs/syntax-update`

### 3. Make Your Changes
Ensure your code follows the project’s style and architecture.

### 4. Write Tests (if applicable)
All compiler and stdlib changes should include tests.

### 5. Submit a Pull Request
Explain:
• what you changed  
• why you changed it  
• how it improves PranaCode+  

---

## Code Style Guidelines

• Keep code readable and modular  
• Use clear naming conventions  
• Document complex logic  
• Avoid unnecessary dependencies
